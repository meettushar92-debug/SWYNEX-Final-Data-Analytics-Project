# Online Retail Sales Analysis - Final Data Analytics Project

## 1. Project Overview

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies. The objective is to clean retail transaction data, perform exploratory data analysis, and present key business insights using Microsoft Power BI.

## 2. Problem Statement

Retail businesses need to understand sales performance across countries, identify top-performing products, and analyze revenue trends. This project explores retail transaction data to summarize these patterns.

## 3. Dataset Information

- **Dataset:** Online Retail II
- **Source:** UCI Machine Learning Repository
- **Period analyzed:** 1 December to 4 December 2009
- **Tools:** Microsoft Excel, Power Query, Microsoft Power BI

The project uses a sample of the original retail dataset.

## 4. Data Cleaning and Preparation - Task 1

The data preparation process included:

- Checking missing values
- Handling missing Description and Customer ID values
- Identifying and removing duplicate records
- Correcting column data types
- Preparing the dataset for analysis

## 5. Exploratory Data Analysis - Task 2

The following analyses were performed:

1. **Country-wise Revenue Analysis:** Compared revenue across countries.
2. **Daily Revenue Trend:** Analyzed revenue from 1 December to 4 December.
3. **Top 10 Products by Revenue:** Identified the top-performing products by revenue.
4. **Average Price by Country:** Compared average product prices across countries.
5. **Negative Quantity Analysis:** Examined transactions with negative quantities.
6. **Average Order Value:** Calculated the average order value.
7. **Country-wise Quantity Analysis:** Compared quantities across countries.

## 6. Power BI Dashboard - Task 3

The dashboard presents key metrics and visualizations, including:

- Total Revenue
- Average Order Value
- Total Quantity
- Negative Quantity
- Revenue by Country
- Daily Revenue Trend
- Top 10 Products by Revenue
- Negative Quantity by Country

## 7. Key Business Insights

- The United Kingdom generated the highest revenue in the working sample.
- Daily revenue peaked on 3 December in the analyzed period.
- The Top 10 Products analysis highlighted the leading products by revenue.
- Negative quantity transactions were identified and analyzed separately.

These findings apply to the sample used in this project.

## 8. Tools Used

- Microsoft Excel
- Power Query
- Microsoft Power BI

## 9. Conclusion

This project provided practical experience in data cleaning, exploratory data analysis, business metrics, and dashboard development. It demonstrates how retail data can be organized and analyzed to support business understanding.
