# Online Retail Sales Analysis — Final Data Analytics Project

## 1. Project Overview

This project was completed as part of my Data Analyst Internship at SWYNEX Technologies.

The objective is to analyze an Online Retail dataset, identify data quality issues, explore sales performance, and present key business insights through a Microsoft Power BI dashboard.

## 2. Problem Statement

Retail businesses need to understand revenue performance across countries, identify top-performing products, and monitor sales trends. This project explores retail transaction data to identify useful patterns and summarize the findings in a dashboard.

## 3. Dataset Information

- **Dataset:** Online Retail
- **Source:** UCI Online Retail II dataset
- **Tools:** Microsoft Excel, Power Query, and Microsoft Power BI

The working dataset is a sample from the original public retail dataset.

## 4. Data Cleaning and Preparation

The data cleaning process included:

- Identifying missing values
- Handling missing Description and Customer ID values
- Checking and removing duplicate records
- Correcting column data types
- Preparing the data for analysis

## 5. Exploratory Data Analysis

The analysis covered:

- Total revenue
- Average order value
- Total quantity
- Revenue by country
- Daily revenue trends
- Top 10 products by revenue
- Negative quantity transactions

## 6. Power BI Dashboard

The dashboard presents key metrics using KPI cards and charts, including country-wise revenue, product performance, daily revenue trends, and negative quantity analysis.

## 7. Key Findings

- **Total Revenue:** 192,734.82
- **Average Order Value:** 420.82
- **Total Quantity:** 102,433
- **Negative Quantity:** -240
- **Highest Daily Revenue:** 68,027.59 on 3 December

These figures relate to the working sample used for the dashboard.

## 8. Tools Used

- Microsoft Excel
- Power Query
- Microsoft Power BI

## 9. Conclusion

This project provided practical experience in data cleaning, exploratory data analysis, KPI reporting, and data visualization. The dashboard helps present retail performance metrics in a clear and structured format.
